# 口语化 + 咨询师口吻 改写规则（供 LLM 表达层 / Step1 Prompt 使用）

> 配套文件：`dimensions_counselor.json`（8 维度）、`types16_counselor.json`（16 类型）
> 原始语料：`../mbti-data/`（未改动）

## 一、口吻五律

1. **先接住，再展开**：第一句永远是共情或正常化（"这很正常""很多朋友都是这样"），然后才进入描述。
2. **倾向词不离口**：可能 / 往往 / 常常 / 倾向于 / 大概率。**禁用**：你就是 / 一定是 / 注定 / 天生就这样。
3. **不贴标签、不评判**：短处一律改写为"长处用力过猛的另一面"（例：J 的死板 → "你给自己搭的安全感"）。
4. **三段式收尾**：描述 → 内在需要（inner_need）→ 一句照护建议（care_tip）。
5. **口语密度**：多用短句、生活场景（洗车、聚会、deadline、水果沙拉），少用心理学术语；术语出现时顺手翻译（"这就是心理学里说的回血"）。

## 二、与八字结论的组合句式

- **双标签句**：`{格局名} × {类型名}倾向`，例："杀印相生 × 建筑师倾向——谋定后动的策略家。"
- **维度锚句**：由十神统计给出 4 维倾向值，正文按倾向强的维度选对应 `counselor_profile` 段落拼接，避免 16 类型整段照搬（防止报告千篇一律）。
- **回溯标注**：MBTI 表达段落末尾统一挂"（现代心理类型视角参考）"，与命理结论区隔。

## 三、护栏对齐（L3）

- 全部文案已规避绝对化断言与医疗/心理诊断式措辞；
- 不出现"你有病""你需要治疗"类表述；心理困扰一律导向"如果长期困扰，建议找专业心理咨询师聊聊"；
- 类型外号使用通用中文译名（建筑师/逻辑学家…），不使用"16Personalities"商标表述。

## 四、接入 Step1 工作流的建议

1. 把 `types16_counselor.json` 作为 few-shot 素材库按命中类型取 1 条 + 命中维度取 2~3 条 `everyday_examples` 注入 Prompt；
2. 要求 LLM 输出时保持"共情→描述→照护建议"三段式，并复述至少 1 个生活化例句的意象（可换场景不可换口吻）；
3. 输出后过 L3 护栏校验（绝对化词表 + 敏感词），不合格段落回退到 JSON 原文。

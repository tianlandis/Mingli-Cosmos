# 融合方法论精读：跨体系怎么"合"而不"打"

> 两个独立来源（中文 AI 命理产品「指南星」、韩国 Saju 应用 Mystic Universe 博客）在方法论上高度收敛，可信度高。

## 一、指南星（guidingstar.ai）—— 重叠/分歧框架

**核心命题**："MBTI 看出『你是谁』，命盘看出『你为什么是这样』。"
- MBTI = 横切面/快照（当下的行为偏好，会随人生事件变 1~2 个字母）
- 命盘 = 纵深/结构（出生那一刻就写定的倾向，不随心情漂移）
- **重叠信号** = 反复出现的模式 → "比较稳固、不太会逆转的倾向，可做长期规划"
- **分歧信号** = 内心两股力量的拉扯 → "不是急着修正，而是先意识到拉扯存在，让两边都有出口"（通常是你最近最耗能的地方）

**具体映射关系**（原文）：
- MBTI 认知功能 ↔ 八字十神结构（Ti/Fi ↔ 比劫、Ne/Se ↔ 食伤）——与我们 `engine/pattern/mbtiMapping.ts` 思路完全一致
- MBTI 内外向偏好 ↔ 紫微主星倾向
- 占星上升星座 ↔ MBTI 外显气质（上升处女 vs ISTJ 的整洁感）

**范例解读的三段结构**（可直接抄进命书 prompt）：
1. 多信号一致 → 指向同一主题（如 INFP 的 Fi + 太阳天秤"需要关系和谐" + 月亮双鱼"吸收他人情绪" → "情绪边界容易模糊"）
2. 一条分歧信号（日主丁火"需要明确投注对象"，与上面三者的"无限接住所有人"相悖）
3. 落到具体行动引导（"回想最近一次为维持和谐而吞掉自己感受的场景"）

**FAQ 话术**（处理用户质疑"矛盾时信哪个"）：转问法——不是"该信哪个"，而是"为什么会矛盾"：后天适应正在对抗天生结构，分歧处往往是最耗能的地方。

## 二、Mystic Universe / getsaju —— 三透镜分层

**分工表**：
| 透镜 | 读什么 | 回答的问题 |
|---|---|---|
| Saju/八字 | 出生时间的五行结构、十神、大运流年 | "原材料是什么？能量集中/缺失在哪？现在什么能量压着我？" |
| 占星 | 太阳/月亮/上升 + 12 宫位 | "我的表达在什么场景显形？" |
| MBTI | 四轴偏好 | "我怎么充电、接收信息、做决定、守承诺？" |

**四元素 → 八字的"情绪翻译"（明确声明：是翻译桥，不是换算表）**：
- 火象（白羊/狮子/射手）＝"先动的节奏" ≈ 火、食伤、比劫的推进力
- 土象（金牛/处女/摩羯）＝"落实的节奏" ≈ 财、官、土元素的结构力
- 风象（双子/天秤/水瓶）＝"连接的节奏" ≈ 食伤、印的言语学习
- 水象（巨蟹/天蝎/双鱼）＝"承载的节奏" ≈ 水、印的同理与想象

**MBTI 四轴 ↔ 命理参照**（配对参考，非一对一）：
- E/I ↔ 食伤/比劫的外显度 + 上升星座的对外反应风格
- S/N ↔ 印/食伤的学习风格 + 水星、9 宫
- T/F ↔ 官/财的现实取向 + 金星、月亮的关系基调
- J/P ↔ 土/官结构 + 固定/变动/开创三模式

**五步应用法**（可做命书"三透镜"段的结构）：
1. 八字定原材料（日主、五行旺衰、最强十神）
2. 占星找表达场景（不止太阳：月亮、上升、重宫位）
3. MBTI 读日常习惯
4. 标注重复出现的关键词（重复词才是稳定信号）
5. **把不匹配变成问题**："不是'为什么不一样'，而是'在什么情境下这一面会出现'"

**合盘应用**（对批次 B 直接有用）：八字看结构互动（合冲刑害），占星看两人互相激活的情感场景，MBTI 解释日常沟通断点（一个要解决方案 T、一个要情绪确认 F）。

## 三、国内"三分法"变体（头条/台湾命理内容，大众话术层）

- 三层模型：先天能量底色（五行）/ 内在心智程序（MBTI、九型）/ 外在行为面具（十神、星座、生肖）
- 台湾命理口诀版：八字=天生骨架、MBTI/星座=心理说明书、易经塔罗=当下气象局
- 融合句式范例："外表是沉稳大山（八字土旺），内里装着白羊座的行动力（星座）"——把跨体系描述拼成一幅肖像而非投票

## 四、对"语料矛盾"的最终启示

1. 成熟产品**不做体系间换算**（都明确声明"翻译不是换算表"）——与我们"星座语料只写能量"的结论一致。
2. 矛盾处理的标准话术是**分层 + 转译**：不一致=不同层/不同情境，写"分歧信号"段落反而是深度卖点。
3. 落地到我们：LLM prompt 里给三套结构化输入（八字批注 / 星座能量风格 / MBTI 档案），指示模型"先找重叠主题，再标分歧信号，分歧用场景提问收尾"——guardrail 端加一条"禁止用单一体系否定另一体系"。

# 星座语料结构模式与一手样例

> 来源：星座百科网（CDP 真浏览器抓取）、Astrogini、今日头条 12 星座完整解析、测测官方文案等。注意：以下样例**全部是无条件人格断言**，仅作结构参考；入库前须按 `corpus-consistency` 规范改写为能量风格措辞。

## 模式 A：关键词表（正负混合，每星座 12~14 词）

星座百科网（2026-02 抓取）样例：

- 白羊：冲动、热情、冒险、积极、敏捷、正义、投入、开拓、自我、好胜、攻击、火爆、草率、征服
- 金牛：物欲、贪婪、享乐稳重、懒惰、倔强、占有、迟缓、实用、忠诚、容忍、审美、条理、温和
- 处女：完美、善良、细致、尽责、分析、自省、服从、挑剔、洁癖、紧张、呆板、畏缩、惶恐、孤独

特征：正面词与阴影词混排（约 6:8），覆盖"闪光点+代价"，比纯彩虹屁可信。

## 模式 B：Positive / Challenging 两分（Astrogini）

- 白羊 Positive: Energetic, adventurous, courageous, confident ｜ Challenging: Impulsive, impatient, self-centered
- 双鱼 Positive: Compassionate, artistic, intuitive, empathetic ｜ Challenging: Escapist, overly trusting, boundaries 弱

可映射到我们 schema：`positiveTraits` / `challengingTraits` 两个字段。

## 模式 C：四段式档案（头条「12 星座完整解析」）

每星座四段：`核心特质` / `优点` / `缺点` / `感情里`，外加固定头信息（日期区间·元素·守护星）。样例（金牛）：核心特质=慢热踏实、隐忍专一、极度缺乏安全感；优点=稳重靠谱、耐力强、审美在线；缺点=固执、敏感别扭、隐忍不爱争吵；感情里=慢热被动→熟悉后温柔体贴，用长久陪伴付出。

## 模式 D：四元素分组先行

「火象=先动的节奏 / 土象=落实 / 风象=连接 / 水象=承载」——先讲元素节奏再落到星座，天然衔接八字五行叙事，降低认知成本。**这是我们元素字段（fire/earth/air/water）的正确用法。**

## 模式 E：恋爱维度独立成库

恋爱魅力（头条）、恋爱性格（新浪）、爱情文案短句（星座智慧屋）——星座站的流量大头在恋爱内容。样例句式（金牛）："记住你奶茶三分糖、保温杯永远装满热水""聊天总提以后咱家装修，偷偷存钱买婚房"——**具象场景 > 抽象形容词**，值得断语库借鉴。

## 模式 F：Superlatives 榜单（社交传播款）

MOST FEARLESS: 白羊/狮子/射手 ｜ MOST LOYAL: 金牛/处女/巨蟹 …… 每个特质配 3 星座，天然适合海报/分享卡片（Phase 5 封存项可复用）。

## 一句话特征（测测官方风格，每星座 3 短语）

白羊=心思单纯、有正义感、勇敢积极；金牛=沉着耐心、脚踏实地、艺术气息；巨蟹=感情真挚、念旧体贴、善解人意。适合 UI 上的星座徽章/tooltip。

## 与我们相容性规范的衔接

以上所有模式的共性 = **无条件断言**（"白羊=热情"）。我们已证明这类词与 32 MBTI 档案必然冲突（384 组合 576 处矛盾）。落地建议：

1. `zodiac.json` 保留行业惯例字段（positiveTraits/challengingTraits 等）**作为展示层语料**——它们只在"你的太阳星座"卡片里出现，与 MBTI 命书语料**不在同一注入上下文**，物理隔离即不打架；
2. 进入 LLM 融合上下文的星座语料，只允许 `energyStyle`（能量风格措辞，过 `detectConflicts` 零矛盾）+ 四元素节奏描述；
3. 断言语料可展示，融合话术只引用"重叠/分歧"框架（见 METHODOLOGY-FUSION.md）。
